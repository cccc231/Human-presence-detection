# v2: 双指标检测 + 1秒聚合

## 版本概述
在 v1 方差指标基础上，新增振幅偏差指标解决静止人体检测问题，并用 1 秒时间窗口聚合替代逐包防抖。

## 算法原理

### 初始化阶段（~4秒）
1. 空房间上电，采集 500 包 CSI 数据
2. 计算每个子载波的平均振幅，存为 `baseline[]`
3. **必须在空房间启动**，否则基准不准

### 运行阶段
每收到一个 CSI 包：
1. 提取子载波振幅，压入 100 包滑动窗口
2. 计算两个指标：
   - **variance_metric**（方差）：窗口内各子载波振幅的方差均值 → 检测运动
   - **amp_dev_metric**（振幅偏差）：当前窗口振幅均值与 baseline 的偏差 → 检测静止存在
3. metric = max(variance_metric, amp_dev_metric)
4. 原始判定：metric > 1.5 → 有人，否则 → 没人
5. 存入 1 秒聚合缓冲区

### 1秒聚合输出
每秒统计一次：
- 统计该秒内"有人"判定次数占总包数的比例
- 比例 ≥ 40% → 最终输出"有人"
- 比例 < 40% → 最终输出"没人"
- 输出格式：`HH:MM:SS, 有人, 2.1477, 45/80`（45次有人 / 80包总计）

### baseline 自适应
- "没人"状态时：baseline 以 0.1%/包速率缓慢更新，适应环境漂移
- "有人"状态时：baseline 冻结，防止人体信号污染基准

## 关键参数
| 参数 | 值 | 说明 |
|------|-----|------|
| WINDOW_SIZE | 100 | 方差计算滑动窗口大小 |
| INIT_SAMPLES | 500 | 初始化采集包数（约4秒） |
| THRESHOLD_HIGH | 1.5 | 单包有人判定阈值 |
| THRESHOLD_LOW | 1.2 | 单包没人判定阈值 |
| AGG_WINDOW_MS | 1000 | 聚合窗口时长（1秒） |
| PRESENCE_RATIO | 0.4 | 有人比例阈值（40%） |
| CONFIG_SEND_FREQUENCY | 80 | TX 发包率 (pkt/s) |

## 相比 v1 的改进
| 项目 | v1 | v2 |
|------|----|----|
| 检测指标 | 仅方差 | 方差 + 振幅偏差 |
| 静止人体 | ❌ 无法检测 | ✅ 通过振幅偏差检测 |
| 状态切换 | 逐包防抖（连续3次） | 1秒窗口聚合（40%比例） |
| 初始化 | 无 | 采集空房间 baseline |
| 环境适应 | 无 | baseline 缓慢自适应 |

## 使用流程
1. **空房间**给 RX 板上电
2. 等待串口输出 `初始化完成` + `预热中...100/100`（约5秒）
3. 确认输出"没人"后，人再进入房间
4. 运行 `python tools/serial_logger.py --port COM28 --output person.csv` 记录数据
